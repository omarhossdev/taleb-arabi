## 🌟 عن المشروع

**طالب عربي (Taleb-Arabi)** هو منصة دراسية شاملة وذكية مصممة لتخفيف ضغوط الدراسة. بفضل واجهته البسيطة والخالية من المشتتات، يساعد الطلاب على تنظيم أوقاتهم، الحفاظ على الاستمرارية، مراجعة البطاقات التعليمية، وتتبع تقدمهم بسهولة تامّة—حتى بدون اتصال بالإنترنت.

> 🏆 *تم تطوير المشروع تحضيراً لـ **جائزة الدولة للمبدع الصغير 2027 في مصر**.*

---

## ✨ المميزات الأساسية

- 📅 **الجدول المخصص:** قم بإنشاء جدولك الدراسي الخاص، وحدد وقتاً لكل واجب أو درس، واجعل جدولك مرتبطاً بأوقات التركيز والمهام اليومية.
- ✅ **المهام اليومية:** تابع مهامك المستخرجة من جدولك، قم بتعديلها أو إنجازها بكل سهولة.
- ⌚ **وقت التركيز (Focus Time):** ابدأ المذاكرة من خلال تبويب مخصص يساعدك على التركيز على مادة واحدة، ويعرض مهامها، ويحفظ وقتك في قاعدة البيانات لتتبع ساعاتك ومعرفة الساعات المتبقية.
- 📝 **ملخصات مراجعة يدويًا:** احصل على ملخصات دراسية بخط اليد تم فحصها للتأكد من جودتها وموافقتها لقواعد الملكية الفكرية بموافقة صناعها.
- 🔔 **تنبيهات تيليجرام اختيارية:** اربط حسابك ببوت تيليجرام مجاني لتلقي إشعارات الجدول والامتحانات والتي يمكنك تخصيصها أو كتمها في أي وقت.
- 🎴 **البطاقات التعليمية (Flashcards):** أضف بطاقاتك التعليمية وكلمات اللغة الإنجليزية الخاصة بك وراجعها يومياً مثل نظام Anki، مع خاصية قراءة الكلمات بصوت روبوت بصوت عالٍ.
- 🔥 **الستريك لوحة الصدارة (Leaderboards حسب الصف):** تتبع ساعات الدراسة اليومية، واكسب النقاط وتنافس مع زملائك! لوحة الصدارة مقسمة حسب الصف الدراسي (لكي يتنافس طلاب الصف الثاني مع بعضهم وليس مع الثانوية العامة)، وتعرض اسم المستخدم والنقط فقط **بدون أي بيانات شخصية تماماً**.
- 📶 **يعمل بدون إنترنت (Offline-First PWA):** قابل للتثبيت على أي هاتف أو سطح مكتب بضغطة زر واحدة، ليعمل معك في أي مكان وزمان.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الإطار (Framework):** [Next.js](https://nextjs.org) (App Router)
- **لغة البرمجة:** [TypeScript](https://typescriptlang.org)
- **التصميم:** [Tailwind CSS](https://tailwindcss.com) & [ShadCN UI](https://shadcn.com)
- **قاعدة البيانات:** [Turso](https://turso.tech) (SQLite) & [Drizzle ORM](https://drizzle.team)
- **التشغيل بدون انترنت:** [Dexie.js](https://dexie.org/)

## 🚀 طريقة البدء وتشغيل المشروع محلياً

1. **استنساخ المستودع (Clone)**
   ```bash
   git clone [https://github.com/omarhossdev/taleb-arabi/](https://github.com/omarhossdev/taleb-arabi/)
   cd taleb-arabi
   ```
2. **تثبيت المكتبات المطلوبة** `pnpm install`
3. **إعداد متغيرات البيئة**

أنشئ ملف .env.local في مجلد المشروع الرئيسي وأضف بيانات قاعدة البيانات الخاصة بك:
   ```bash
   TURSO_DATABASE_URL=your_turso_url
   TURSO_AUTH_TOKEN=your_turso_token
   AUTH_SECRET=your_auth_secret
   ```

<p dir="rtl">(You can generate an AUTH_SECRET using `openssl rand -base64 32`)</p>

4. **تحديث قاعدة البيانات** `pnpm db`
5. **تشغيل خادم التطوير** `pnpm dev`
